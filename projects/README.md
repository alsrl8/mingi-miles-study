# Learning projects

This directory contains build-first learning projects. A project begins with a
useful artifact, then uses implementation evidence to reveal which concepts are
worth studying. Projects must not introduce a subject merely because it is a
common prerequisite or a perceived knowledge gap.

## Active projects

- [`agent-run-observer`](agent-run-observer/README.md): compare two AI agent
  runs and make differences in their execution flow visible.

Current execution state belongs in [`maps/progress.md`](../maps/progress.md).
Stable requirements and commands belong in each project README.
